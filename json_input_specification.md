# Спецификация входных json-файлов

**версия 1.0**

## Описание формата

Описание моделей (детекторы, источники, анализаторы, коллиматоры, параметры для расчёта) для расчётных модулей в формате json.

В корне json ключ -- тип модели: "Detector", "Source", "Analyzer", "Collimator", "CalculationParameters", "ContainerSource", значение -- объект (словарь).



## Описание модели детектора (Detector)

У объекта должен быть тип `Type`: `"Type": "DetectorType"`, где DetectorType: `COAXIAL`, `SCINTILLATOR`, `COAX_WELL`.

Размеры указываются в секции (объекте) `"Geometry": "LayerName": double_value`.

Материалы указываются в объекте "Material": для каждого слоя указывается материал:

```json
"LayerName": {
	"rho": double_value,
    "fraction_type": "MASS",
    "elements": [
        {
            "z": int_value,
            "frac": double_value
        }
    ]
}
```



## Описание модели источника (Source)

Тип источника (`Type`): `POINT`, `CYLINDER`, `MARINELLI`, `CONE`.

Описание секции размеров (`Geometry`) и материалов (`Material`) аналогичны формату детектора



## Описание модели анализатора (Analyzer)

Модель анализатора имеет фиксированный набор полей:

```json
"Name": "DSpec_8K_3Mev",
"FWHM_122": 0.77,
"FWHM_662": 1.26,
"FWHM_1332": 1.73,
"kev_per_ch": 0.3662,
"N_ch": 8192
```

- `FWHM_122`, `FWHM_662`, `FWHM_1332` -- значения FWHM для энергий 122, 662 и 1332 кэВ, должно быть указано минимум одно из полей.

- `kev_per_ch` -- цена канала (обязательное поле)

- `N_ch` -- число каналов (обязательное поле)
- `Name` -- имя анализатора (необязательное поле)



## Описание модели коллиматора (Collimator)

Тип коллиматора (`Type`): `TYPE1`, `TYPE2`.

Описание секции размеров (`Geometry`) и материалов (`Material`) аналогичны формату детектора



## Описание модели источников в контейнере (ContainerSource)

Содержит секцию `Cells`, в которой массив слоёв. Необязательное поле `Name`. И поле `DetectorPosition`.

Каждый слой состоит из полей:

- `Shape` -- геометрическая форма слоя, возможные значения:
    - Point -- точка,
    - CylX, CylY, CylZ -- цилиндр, соосный соответствующей оси
    - Cuboid -- прямоугольный параллелепипед,
    - Sphere -- сфера
    - ConeX, ConeY, ConeZ -- конус, соосный соответствующей оси
    - ChamferedCuboidX, ChamferedCuboidY, ChamferedCuboidZ -- кубоид с фаской, соосный соответствующей оси
    - Prism -- призма
- `ParentIdx` -- индекс родительского слоя (-1 -- если слой корневой -- нет родительского слоя),
- `ChildIndex` -- массив индексов дочерних (вложенных) слоёв,
- `Dimensions` -- размеры слоя в см, содержит поля `Dim1`, `Dim2`, ...
- `Position` -- положение центра слоя (`x`, `y`, `z`) в см, центр координат в центре корневого слоя,
- `DirectionAxis` -- направление слоя (пока валидно только для Prism), может принимать только значения `X`, `Y`, `Z`
- `Material` -- материал слоя
  - `rho` -- плотность материала,
  - `elements` -- массив элементов (`z`, `frac`)

`DetectorPosition` -- положение центра детектора относительно центра источника

	- `detX`, `detY`, `detZ` -- координаты центра детектора в см,
	-  `detPhi`, `detTheta` -- направление детектора в радианах



## Описание параметров расчёта (CalculationParameters)

Секция CalculationParameters имеет набор полей:

```json
"useGLECS": false,
"useEPDL97": false,

"calc_electron_real": false,

"calc_spectrum": false,

```


## Описание отклика детектора (DetectorResponse)

```json
"DetectorResponse": {
    "Emin": float,  // параметры энергетической сетки, для которой был рассчитан отклик детектора
    "Emax": float,
    "N_points": int,
    "Nmin": int,  // число испытаний -- неиспользуемые поля
    "Nmax": int,
    "Response": [
        {  // точка с откликом детектора
            "Energy": float, // энергия в МэВах
            "fep": float, // поля со значением отклика
            ...
        },
        ...
    ]
}
```

Название и начения полей в отклике:
- fep -- full energy peak, эффективность пика полного поглощения
- sep -- single escape peak -- эффективность в пике одиночного вылета
- dep -- double escape peak -- эффективность в пике двойного вылета
- p511 -- эффективность аннигиляционного пика
- dfep, dsep, ddep, dp511 -- соответствующие относительные неопределённости в %
- normalized_* -- соответствующие относительные величины (относительно суммарного числа зарегистированных гамма-квантов от источника)
- nxep -- x-ray escape peak -- число пиков рентгеновского вылета
- exep -- массив с энергиями пиков рентгеновского вылета в МэВ
- xep -- массив с эффективностями пиков рентгеновского вылета
- dxep -- относительные неопределённости эффективности пиков рентгеновского вылета
- xep_total, dxep_total -- суммарная эффективность и отн. неопределённость пиков рентгеновского вылета. Данная величина вспомогательная и не имеет смысла.
- normalized_xep, normalized_xept -- относительные величины
- a -- массив с коэффициентами аппроксимируещего комптоновский континуум полинома
- b -- массив с коэффициентами аппроксимируещего рассеянное излучение полинома

## Описание физического спектра (PhysSpec)

```json
"PhysSpec": {
    "UncollidedFlux": float,  // интегральный поток нерассеянного излучения
    "dUncollidedFlux": float, // погрешность интегрального потока нерассеянного излучения
    "CollidedFlux": float,    // интегральный поток рассеянного излучения
    "dCollidedFlux": float,   // погрешность интегрального потока рассеянного излучения
    "PeaksEnergy": [float, ...],    // энергия пиков в МэВах
    "PeaksIntensity": [float, ...], // интенсивность пиков: I * A (интенсивность линии умноженная на активность источника)
    "PeaksArea": [float, ...],      // площади пиков
    "ContinuumdE": float,           // шаг для сетки континуума
    "ContinuumEnergies": [float, ...], // энергии сетки континуума
    "ContinuumCounts": [float, ...]    // отсчёты в узлах сетки континуума (каналах)
}
```

## Описание информации об матрице отклика (ResponseMatrix)

```json
"ResponseMatrix": {
    "Channels": int,        // число каналов в матрице (обычно равно числу каналов анализатора)
    "KevPerChannel": float, // цена канала: E_max / Channels
    "Filename": "filename.mtx", // имя файла с матрицей отклика
    "Filepath": "filename.mtx", // полный путь к файлу с матрицей отклика
    "WO_Peaks": true        // матрица отклика с пиками или без
}
```
