
# Спецификация out-файлов

## Нормальный режим

В **нормальном режиме**, т.е. при успешном завершении расчёта, tccfcalc.out файл содержит результаты расчёта эффективности и поправок на истинное суммирование.

**Секция Decay branch(es)** -- информационная секция, содержит ветки распада, которые моделировались при расчёте.
Запись `Co-290   B-  Co-290 (0 fs) - 100%` означает, что рассчитывалась эффективность по энергетической сетке, Co-290 -- фиктивный радионуклид.

**Секции Date, Time** -- время расчёта

**Секция Calculation settings** содержит значения параметров расчёта, модели детектора и геометрии

**Number of simulated decays** -- число проведённых испытаний

**Results** содержит таблицу с результатами расчёта, колонки разделены символом табуляции.

Колонки:
- "##" -- порядковый номер линии, начиная с 1
- "E, MeV" -- энергия линии
- "I" -- интенсивность линии
- "dI(%)" -- относительная неопределённость интенсивности линии в %
- "CF" -- correction factor, поправка на истинное суммирование, для режима расчёта эффективности равна 0
- "dCF(%)" -- относительная неопределённость поправки на суммирование
- "Eff" -- эффективность регистрации
- "dEff(%)" -- отн. неопределённость эффективности регистрации
- "Areas" -- площади пиков -- число зарегистированных фотонов с данной энергией
- "AreasCoi" -- площади пиков в режиме истинного суммирования

**Coincidence sum peaks** может присутствовать в режиме расчёта поправок на истинное суммирование. В этой секции выводится список пиков суммы, которые не попали на пики полного поглощения. Список в виде таблицы.

Колонки:
- "E, MeV" -- энергия линии
- "AreasCoi" -- площади пиков в режиме истинного суммирования

## Режим ошибки

Если расчёт завершился с ошибкой, то в этом файле содержится словесное содержание ошибки, например: "Sum of branching ratios is zero"
